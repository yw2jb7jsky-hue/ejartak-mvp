# متجر المكتب

واجهة عامة أولية لكل مكتب تأجير سيارات.

## المزايا الحالية

- هيدر جذاب وأنيق
- قسم hero/banner للتسويق
- بطاقات سيارات مع الأسعار
- أزرار حجز وتجربة مستخدم مبسطة

## الملفات

- `index.html`: الصفحة الرئيسية
- `styles.css`: تنسيق الواجهة
- `app.js`: بيانات السيارات والـ interactions
