# إيجار تك

منصة SaaS B2B موجهة لأصحاب مكاتب وشركات تأجير السيارات.

## الهدف
توفير نظام احترافي يساعد أي مكتب تأجير سيارات على:
- إنشاء متجر إلكتروني خاص به
- إدارة السيارات والأسعار
- استقبال الحجوزات
- متابعة الطلبات والعملاء
- توسيع النشاط رقميًا

## الفئة المستهدفة
أصحاب مكاتب التأجير، سواءً الصغيرة أو المتوسطة أو ذات الفروع المتعددة.

## التقنية المقترحة
- Frontend: Next.js 14
- Backend: NestJS
- Database: PostgreSQL
- Auth: JWT
- Styling: Tailwind CSS
- Deployment: Vercel + Render
