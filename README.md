# إيجار تك

منصة SaaS B2B موجهة لأصحاب مكاتب وشركات تأجير السيارات.

## ما هي المنصة؟

إيجار تك هي منصة تساعد أصحاب مكاتب التأجير على إنشاء موقع تجاري خاص بهم، وإدارة أسطول السيارات، وعرض خدمات التأجير للعملاء عبر الإنترنت.

## لماذا هذه الفكرة؟

- لا تركز المنصة على العميل النهائي مباشرة
- بدلاً من ذلك، تمكين أصحاب المكاتب من امتلاك منصة احترافية خاصة بهم
- إدارة السيارات، الحجز، الطلبات، والتسعير من واجهة واحدة
- دعم النمو الرقمي للمكاتب الصغيرة والمتوسطة

## MVP الذي تم تطويره

تم الآن إعداد أول نسخة قابلة للتشغيل من الواجهة الأمامية للمنصة، وتتضمن:

- لوحة تحكم مديرية لإدارة المكاتب
- متجر إلكتروني لعرض السيارات المتاحة
- قوائم سيارات مع الفلاتر
- نموذج حجز للعميل
- Cards إحصائية ولوحة الطلبات

## هيكل المشروع

```bash
.
├── apps/

├── README.md

```

## تشغيل المشروع محليًا

بما أن المشروع الآن عبارة عن صفحات ويب ثابتة (UI MVP) يمكن فتح الملفات مباشرة في المتصفح، أو تشغيل خادم صغير محلي مثل:

```bash
python -m http.server 8000
```

ثم زيارة:

- http://localhost:8000/apps/storefront/
- http://localhost:8000/apps/admin/

## الصفحات المتاحة

- متجر المكتب: `apps/storefront/index.html`
- لوحة الإدارة: `apps/admin/index.html`

## الخطة المستقبلية

1. إضافة نظام تسجيل الدخول
2. ربط backend مع قاعدة بيانات
3. إدارة السيارات والطلبات بشكل حقيقي
4. دمج الدفع وإشعارات واتساب
5. بناء تطبيق محمول
